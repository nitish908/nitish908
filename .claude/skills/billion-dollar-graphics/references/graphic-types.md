# Graphic Type Catalog

From *Do-It-Yourself Billion Dollar Graphics* (Mike Parkinson). Definitions are drawn directly from the book's glossary. Grouped by the kind of relationship each type is built to show — pick the group that matches your content first, then the specific type within it.

## Comparing quantities / showing trends
- **Bar Chart** — depicts changes in quantitative data using bars, where bar size represents proportional value.
- **Line Chart** — shows changes in quantitative data using lines, where line position represents proportional value. Best for trends over time.
- **Area Chart** — depicts continuous quantitative data (usually over time) using filled areas to communicate amounts, time frames, or values.
- **Point Chart** — shows quantitative data using plotted points.
- **Bubble Chart** — uses circles/spheres to show ranges of quantitative data; can also illustrate uncertainty of a predicted value.
- **Candlestick Chart** — analyzes values/sales of stocks, bonds, commodities over time (price on the vertical axis, time on the horizontal).
- **Scale Graphic** — a visual metaphor that illustrates comparison directly (e.g., a balance scale).
- **Circle Charts** — a family of circular quantitative graphics: radar graphs, sector graphs, circle column graphs, and similar.

## Showing composition / parts of a whole
- **Pie Chart (Segmented Chart)** — communicates percentages of a whole using proportional segments.
- **Waterfall Diagram** — a process diagram type depicting the linear, progressive flow of steps or values (e.g., how a total builds or erodes).
- **Building Blocks** — interconnects data to show how elements work together to create a larger unit.
- **Stacked Diagram** — depicts hierarchy/arrangement/structure/relationship of a group of elements; can also show a process flow, similar to a pyramid or process diagram but more versatile.

## Showing hierarchy / structure
- **Organizational Chart** — depicts the hierarchy, arrangement, structure, and/or relationship of a group (typically an organization and its people).
- **Pyramid Graphic** — a visual metaphor for hierarchy where bottom elements support the elements above.
- **Risk Matrix** — a table depicting varying levels of risk as affected by one or more variables.
- **Table (Matrix)** — a grid correlating data along two axes; row/column intersections reveal the linking data.

## Showing process / flow / time
- **Process Diagram (Flow Chart)** — shows the flow or progression of steps in a process or event.
- **Timeline** — linearly represents time.
- **Gantt Chart** — a bar chart representing time and activity, used for planning, tracking, and controlling schedules.
- **Calendar** — a table showing years/months/weeks/days.
- **Step-by-Step Graphic** — depicts the execution of a linear process.
- **Stair Graphic** — a visual metaphor depicting steps in a process.
- **Looping Graphic** — depicts a repeating process or event.
- **Conveyor Belt Graphic** — a visual metaphor for a repeatable linear process.
- **Spiral Graphic** — a visual metaphor illustrating the evolution of something through a cyclical process.
- **Pipe Graphic** — a visual metaphor representing the isolated, linear flow of elements.
- **Funnel Graphic** — a visual metaphor for elements passing through a conduit, resulting in effective allocation, consolidation, or organization.
- **Gear Graphic** — a visual metaphor depicting how parts work together; often illustrates process and interoperability.
- **Vee Diagram** — a process-diagram variant illustrating relationships between two arms of a "V" and a verification path between interoperable elements.

## Showing connection / relationship / transition
- **Bridge Graphic** — a visual metaphor for the connection or transition between two actions, concepts, or entities.
- **Road Graphic (Path Graphic)** — a visual metaphor for the path from the "as is"/before state to the "to be"/after state.
- **Before and After Graphic** — directly compares the "as is" state to the "to be" state.
- **Network Diagram** — shows the connections between elements composing a network.
- **Venn Diagram** — shows the relationship and/or synergy of disparate elements through their overlap.
- **Puzzle Graphic** — a visual metaphor for the synergy of separate elements creating a new whole.
- **Peg Graphic** — shows the interconnectivity of entities/ideas creating a unified whole (think interlocking blocks).

## Showing physical / spatial structure
- **Cross Section Diagram** — an entity is "cut in half" so its different layers can be viewed and defined individually.
- **Cutaway Diagram** — like a cross section, but the inner workings are seen through a missing/transparent portion of the outer layer.
- **Exploded Diagram** — shows an entity's disassembled parts positioned to indicate how they reassemble.
- **Floor Plan** — depicts the layout of a room or level within a building.
- **Map Graphic** — shows a region of physical space (continent, country, city, building, etc.).
- **Dome Graphic** — a "snow globe"-style visual metaphor for containment; especially good for communicating protection/security.

## Consolidating multiple metrics at once
- **Dashboard Graphic** — presents multiple metrics, potentially using multiple graphic types, in one consolidated format (think of a car's dashboard).
- **Gauge Graphic** — a visual metaphor using readouts/measurement tools to depict data for analysis.

## Illustration / imagery
- **Illustration** — a visual representation used to make a subject more appealing or easier to understand.
- **Photograph** — a picture of a person, place, or thing.
- **Collage** — composed of juxtaposed images.
- **Icon** — a representational element visually analogous to an action, concept, or entity.
- **Symbol** — a representational element with a learned/accepted meaning for an action, concept, or entity.

## Conceptualization methods (for reference — see SKILL.md Step 2)
- **Literal Method** — show exactly what's described to clarify, explain, or support a claim.
- **Substitution Method** — substitute one action/concept/entity for another via visual metaphor, analogy, or simile.
  - **Metaphor** — replaces one thing with another that shares its applicable characteristics (implicit comparison).
  - **Analogy** — augments one thing by comparing it to another with logical relevance, often used to build a logical argument ("if similar in one way, might be similar in others").
  - **Simile** — augments one thing via a comparison to another with logical relevance (similar to analogy).
- **Quantitative Method** — capture descriptions of quantity (value, amount, time) and choose from the quantitative graphic types above.
- **Assembly Method** — capture important chunks of information and assemble them (like building blocks) to better show relationships or interactions.
